# Headline Summarizer

A simple Python script that takes recent headlines, filters them by topic, and generates a short summary.

This started as an AI-generated draft and was cleaned up and tested afterward. It shows a practical example of using AI to build a small working tool quickly, then refining the output for better results.

## What it does
- Pulls or accepts a list of headlines
- Filters by topic
- Creates a concise summary

## Notes
The initial version was generated with Claude and then edited for clarity, edge cases, and readability.
